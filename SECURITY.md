# Security policy

Please do not put API keys, player identifiers, raw chat logs, or other personal data in issues, pull requests, screenshots, or commits.

If you discover a security issue, report it privately to the repository owner with a minimal reproduction. Do not publish a proof of concept containing real credentials or data.

This project only supports local use of an API key. The key is entered in the browser, forwarded for one local request, then cleared from the page. It must never be committed to Git.
